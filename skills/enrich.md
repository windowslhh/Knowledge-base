# 丰富工作流 (Enrich)

## 触发场景
- 新页面创建后
- 用户请求增强某页面的交叉引用

## 步骤

### 1. 读取目标页面
```json
{"tool": "read", "slug": "target-slug"}
```

### 2. 发现关联
使用页面的关键词搜索相关页面：
```json
{"tool": "search", "query": "页面关键概念"}
```

### 3. 添加交叉引用
在目标页面的内容中，将相关实体替换为 `[[wiki-link]]` 格式。

### 4. 双向引用
在被引用的页面中也添加对目标页面的引用。

### 5. 补充标签
基于关联页面的标签，为目标页面添加缺失的标签。

### 6. 验证
```json
{"tool": "backlinks", "slug": "target-slug"}
```
确认反向链接已正确建立。

## 规则
- 只有确实存在语义关联才添加链接
- 避免过度链接（一个页面通常 5-15 个出链）
- 链接文本应有意义：`[[slug|显示文本]]`
