# 查询工作流 (Query)

## 前置条件
- 用户提出了一个问题

## 步骤

### 1. 搜索知识库
使用 `query` 工具进行混合搜索：
```json
{
  "question": "用户的问题",
  "limit": 5
}
```

### 2. 深度阅读
对搜索结果中相关度高的页面，使用 `read` 获取完整内容：
```json
{
  "slug": "result-slug"
}
```

### 3. 扩展搜索（可选）
如果结果不充分：
- 使用 `backlinks` 查找关联页面
- 使用 `tags` 查找同类页面
- 用不同关键词重新 `search`

### 4. 综合回答
- 综合所有读取的页面信息
- 用 `[[slug|标题]]` 引用来源页面
- 如果信息不足，明确告知

## 输出格式
回答应该：
- 直接回答问题
- 引用知识库中的具体页面
- 标注信息的时效性（基于 timeline）
