# 简报工作流 (Briefing)

## 触发场景
- 用户请求某主题的综合概要
- 用户需要了解某个时间段的动态

## 步骤

### 1. 主题搜索
```json
{"tool": "query", "question": "简报主题", "limit": 10}
```

### 2. 深度阅读
对所有相关页面执行 `read`，收集：
- Compiled Truth（当前事实）
- Timeline（历史事件）
- 标签和链接

### 3. 组织信息
按以下结构组织简报：

```markdown
# [主题] 简报

## 概要
一段话总结核心要点。

## 关键实体
- [[entity-1|名称]] — 角色/关系
- [[entity-2|名称]] — 角色/关系

## 时间线
- **YYYY-MM-DD** — 事件摘要 ([[来源页面]])
- **YYYY-MM-DD** — 事件摘要 ([[来源页面]])

## 关键洞察
1. 洞察一
2. 洞察二

## 信息缺口
- 尚未确认的信息
- 需要补充的方面
```

### 4. 输出
直接输出简报内容。如果用户要求，可保存为页面：
```json
{
  "tool": "write",
  "slug": "briefings/topic-YYYYMMDD",
  "title": "主题简报 YYYY-MM-DD",
  "compiled_truth": "简报内容...",
  "tags": ["简报", "主题标签"]
}
```
